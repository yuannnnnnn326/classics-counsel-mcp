# Classics Counsel MCP

一个可扩展、自托管的中国古典典籍参考 MCP。

它不是“让古人替你做决定”，而是当你面对现实中的选择、人际关系、工作、学习、家庭、朋友、师生关系等问题时，从已收录典籍中检索相关原文、历史案例和思想视角，作为参考。

## 设计目标

- 一个插件统一管理多部典籍
- 后续新增典籍时，不需要修改核心搜索逻辑
- 支持查看书目、搜索原文、读取上下文
- 保留原文出处和篇章信息
- 后续可继续增加语义检索和“相似历史案例”功能
- 最终判断仍由用户自己做

## 第一版 MCP 工具

- `list_books`：查看已收录典籍
- `get_book_info`：查看某本典籍的信息
- `search_passages`：跨典籍检索原文
- `get_passage`：读取某段原文及上下文
