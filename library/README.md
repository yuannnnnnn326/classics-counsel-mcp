# library/

这里是典籍原始文本库。

## 最简单的规则

**一本书 = 一个 UTF-8 `.txt` 文件。**

例如：

```text
library/
├── 史記.txt
├── 論語.txt
├── 資治通鑑.txt
├── 戰國策.txt
└── 莊子.txt
```

上传新 TXT 后，不需要修改 `worker.js`。MCP 会动态读取当前目录中的 `.txt` 文件。

## 文件名

推荐使用简短、稳定、可直接作为书名识别的文件名：

```text
戰國策.txt
```

不推荐：

```text
戰國策_(髙誘注,_姚宏續注,_四庫全書本)_最终版_整理.txt
```

底本、注本、来源与版本信息统一写进根目录的 [`SOURCES.md`](../SOURCES.md)。

## 文本格式

推荐：

- UTF-8 编码；
- 尽量保留自然段；
- 不要求转 Markdown；
- 不要求手工编号；
- 不要求人工切成数据库条目；
- 可以保留卷、篇、章标题；
- 如果文件含大量网页导航、现代说明或校注，最好在 `SOURCES.md` 里说明。

## 新增后多久能看到

Worker 对 GitHub 目录列表有短暂缓存。通常上传后等待约 60 秒，再调用 `list_books` 即可看到新书。

如果 ChatGPT 的 MCP 工具定义本身发生变化，需要在自定义 App 设置里“刷新工具”；**单纯新增 TXT 不需要刷新工具定义。**

## 版权

不要上传你无权公开再分发的现代译文、现代注释或出版社电子版。

古籍原文是否公版，与“你拿到的这个电子整理文本是否允许公开再分发”是两回事。来源与许可说明见 [`SOURCES.md`](../SOURCES.md)。
